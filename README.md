# 🎬 Нарезки Кино — Telegram-бот

Полнофункциональный бот для просмотра и скачивания кино-нарезок с обязательной подпиской на канал, VIP через Telegram Stars (подарки + скрины), рефералкой, партнёркой и админ-панелью.

## Возможности

### Для пользователей
- **Обязательная подписка** на канал перед использованием
- **Меню кнопками в чате** (InlineKeyboard)
- **Профиль**: юзер, просмотрено кино, дни с нами, реферальная ссылка (15% от покупок)
- **VIP**: 150 ⭐ / месяц (цена меняется админом)
  - Оплата: подарок админу → скрин → заявка → одобрение → VIP автоматически
- **Поиск кино** по названию / жанру / ID
  - Выдаёт ссылку на YouTube-канал
  - VIP может скачать в 1080p (до 5 ГБ, лимит Telegram ~50 МБ без Local Bot API)
- **О боте** — текст редактируется админом
- **Партнёрства**: требования по подписчикам, ссылки, 5-сек шаблон, 50 ⭐ за 10к просмотров

### Админ-панель (`/admin`)
Только для одного `ADMIN_ID`:
- Статистика
- Пользователи
- Партнёры (со ссылками)
- Заявки на оплату (одобрить / отклонить)
- Добавить кино (ID, название, жанр, YouTube-ссылка, обложка)
- Удалить кино
- Изменить цену VIP
- Изменить текст «О боте»

## Быстрый старт (локально)

1. Создай бота у [@BotFather](https://t.me/BotFather) → получи `BOT_TOKEN`
2. Узнай свой ID у [@userinfobot](https://t.me/userinfobot)
3. Создай канал и добавь бота админом (чтобы проверять подписку)
4. Скопируй `.env.example` → `.env` и заполни:

```env
BOT_TOKEN=...
ADMIN_ID=...
CHANNEL_ID=@your_channel
CHANNEL_LINK=https://t.me/your_channel
ADMIN_USERNAME=your_username
DEFAULT_VIP_PRICE=150
```

5. Установи зависимости и запусти:

```bash
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
python bot.py
```

## Деплой на Railway (24/7)

1. Зарегистрируйся на [railway.app](https://railway.app)
2. **New Project** → **Deploy from GitHub** (или загрузи ZIP)
3. Подключи репозиторий / загрузи этот проект
4. В **Variables** добавь все переменные из `.env.example`:
   - `BOT_TOKEN`
   - `ADMIN_ID`
   - `CHANNEL_ID`
   - `CHANNEL_LINK`
   - `ADMIN_USERNAME`
   - `DEFAULT_VIP_PRICE` (опционально)
5. Railway автоматически соберёт Docker-образ и запустит бота
6. В логах увидишь: `Бот запущен: @your_bot`

### Важно для Railway
- Используется **long polling** (не нужен публичный URL)
- SQLite-база лежит в `./data/bot.db` (при редеплое данные могут пропасть — для продакшена подключи PostgreSQL и укажи `DATABASE_URL`)
- Скачивание видео ограничено лимитом Telegram-бота (~50 МБ). Для больших файлов нужен Local Bot API или внешнее хранилище
- Чтобы добавить 5-секундный рекламный шаблон для партнёров — положи файл `data/partner_ad_template.mp4`

## Cloudflare R2 (скачивание больших файлов)

Без R2 бот может отправлять файлы только до ~50 МБ.  
С R2 — любые размеры (до 5 ГБ), пользователь получает прямую ссылку.

### Переменные в Railway / .env:

```env
R2_ACCOUNT_ID=...
R2_ACCESS_KEY_ID=...
R2_SECRET_ACCESS_KEY=...
R2_BUCKET_NAME=narezki-kino
R2_PUBLIC_URL=https://pub-xxxxxxxx.r2.dev
```

Как получить эти данные — смотри инструкцию в чате (шаги в Cloudflare Dashboard).

После добавления переменных **перезапусти** сервис на Railway.
